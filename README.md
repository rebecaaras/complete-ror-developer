## [Ruby on Rails Complete Developer](https://www.udemy.com/course/the-complete-ruby-on-rails-developer-course/) — Exercises & Projects

The course is given in Rails 5 and 6, but I solved then while doing the necessary adjustments to run in Rails 8 and Ruby 4.7.

## Topics covered include

* Ruby fundamentals & Object-Oriented Programming
* Rails MVC architecture
* CRUD and ActiveRecord
* Database associations
* Authentication & authorization
* Devise
* RESTful APIs
* Ajax, JavaScript & jQuery
* ActionCable & WebSockets
* Bootstrap, Semantic UI & MaterializeCSS
* Testing
* Git & GitHub
* AWS S3 & SendGrid
* Stripe payments
* Multi-tenancy
* Production deployment
